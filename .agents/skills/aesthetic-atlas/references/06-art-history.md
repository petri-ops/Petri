# Art History — 流派取舍表（取什么，拒什么）

"Master level" is knowing which movements serve the product and which to refuse. Never apply a movement as a costume.

| Movement / tradition | Core grammar | Take for UI | Refuse |
|---|---|---|---|
| Minimalism & Swiss International (1950s–) | Grid, mathematical spacing, asymmetric balance, single accent, sans-serif | 12-col thinking, 8px base, one accent, flush-left hierarchy | Cold impersonality; Helvetica forced onto Chinese text |
| De Stijl / Constructivism | Orthogonal geometry, primary accents, offset composition | Offset-quadrant mark, grid discipline, one highlighted cell | Large primary-color fields across whole UI |
| Bauhaus / Itten | Form follows function; color contrasts vocabulary | Function-led components; seven contrasts for color reasoning | Period ornament |
| Suprematism (Malevich) | Pure geometric form, reduction | Simple geometric icons and empty-state figures | Abstract art as decoration without meaning |
| Song/Yuan literati painting | 留白, 平远, 墨分五色, 气韵 | Paper tone, hairlines, tonal depth, restraint | Brush-stroke textures, fake calligraphy |
| Chinese seal / 印章 | One red mark, placed with intent, small area | One accent "seal" per view; <5% area | Multiple badges competing |
| Japanese wabi-sabi / ma | Imperfection, negative space, interval | Open ring (不圆满), generous 间, asymmetry | Grunge, distress filters |
| Art Deco | Symmetry, geometry, luxury materials | (rarely) ceremonial identity surfaces | Gold gradients, ornament overload |
| Brutalism / Neo-brutalism | Raw structure, hard edges, high contrast | Honest structure, no fake polish | Thick black borders, shock contrast in tools |
| Vintage analog / retro film | Grain, light leaks, faded color | Warm neutral paper tone (abstracted) | Grain overlay, VHS effects |
| Glassmorphism / Spatial UI | Blur, translucency, depth | One meaningful elevated overlay | Default glass panels, parallax, 40px blur |
| Memphis / Pop | Playful color, pattern | (almost never in pro tools) | Confetti, clashing palettes |

## Decision rule

For a proposed style element: (1) name its movement; (2) state the structural principle it expresses; (3) show that principle improves a user task or the product identity; (4) show it does not violate the host design system. If any step fails, refuse it.

## Provenance note

Movement characterizations are standard art-historical knowledge; consult canonical museum/academic sources when a claim is contested. This file is a decision aid, not an art-history textbook.
