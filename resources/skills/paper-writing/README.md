# 论文写作保真（paper-writing）

面向论文/学术文本的写作与修改保真 Skill。手册正文在 `prompts/system.md`，经 `skill_discover` / `skill_get` 消费。

## 适用场景

- 摘要/引言/方法/结果/讨论/结论/回复审稿意见/中文润色。
- 用户要求「改写但不要改变事实、归因、确定程度、数字」。

## 输入约定

- 用户提供完整原文（文件路径或粘贴文本）与改写目标。
- 方法/结果段的数字、单位、统计量、公式按**逐字符**锁定，只校验不改。
- 英文论文覆盖不在本版范围（用户裁决另批）。

## 产出

- 原句 → 改写句 → 保真说明三栏对照表。
- 中文 F 类六项命中报告、数字锁定校验清单、`〈未覆盖：…〉` 清单。
- 用户逐条裁决后才落盘；不静默写文件。
