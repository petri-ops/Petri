### 3.3 插队与重排规则

- 实机出现**预算相关缺陷**（熔断失准/压缩误伤）→ MDL-1 立即插队当前波（计量是压缩链地基）。
- 依赖件提前收口 → 后件可提前进入，但**硬依赖不得倒置**。
- 波内顺序为建议序，可按用户裁决换位；独立件（§3.1）可任意插队。
- 单工作包串行纪律不变：同一时间仅一个 active 包；每包启动照常过立项检查单。

### 3.4 波内零停顿条款与预裁决缺省（2026-10-10 用户裁决「波内 我需要 0 停顿」）
