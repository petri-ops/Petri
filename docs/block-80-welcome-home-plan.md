## 1. 用户裁决

- 「现在点击新建任务 就是跳转到 工作台页面 不过我觉得工作台页面没有意义 能否取消工作台页面呢」
- 「点击新建任务 模仿 ZCode 这个页面 内容要和我们项目一致 不是复刻」（附 ZCode 欢迎页截图：问候语 + 项目/分支选择 + 大输入框 + 快捷任务 chips）

## 2. 目标形态

- `/` 路由 = 欢迎页：时段问候 + 项目下拉（既有项目）+ 当前分支徽标 + 首问输入框 + 领域快捷 chips（差异分析/富集分析/单细胞聚类/报告解读，点击填充 starter prompt）。
- 发送 = `createConversation(project)` 落库 → sessionStorage 交接 `{conversationId, prompt}` → 导航 `/project/:id` → 工作区会话种子完成即派发 `copilotAsk` 启动首个任务。
- 工作台页面退役为 `/projects`「项目管理」（项目卡 + 全部创建流保留：本地目录/手输/SSH/空白），欢迎页下拉尾部「管理项目…」可达；冷启动自动跳最近项目行为拆除（落点改为欢迎页）。
- 标题栏「新建任务」（UI-335）落点即 `/` 欢迎页，标签行为不变。

## 3. 非范围（exclusions）

- 分支切换不在欢迎页（checkout 属变更操作，留在审阅面）；欢迎页分支为只读徽标。
- 不做账号/多用户、不做模板市场；chips 为静态 starter prompt。
- 旧工作台创建流零功能损失（整体平移 /projects）。
- 不外推 packaged/Provider/GA（G0 纪律）。

## 4. 验收门

- 零网络测试（问候分段/项目选择/chips 填充/发送创建会话+sessionStorage 交接）。
- home 定向回归（/projects 化后工作台视图常显、无自动跳转）。
- 实机 CDP：`/` 欢迎页渲染（问候/项目下拉/输入框）→ 选项目输入首问发送 → 落工作台会话启动。证据 `acceptance/block-80/`。
- 治理门禁：docs:check / ui:audit:check。
