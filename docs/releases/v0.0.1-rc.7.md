# BioF3 Desktop v0.0.1-rc.7

发布日期：2026-07-21
状态：已发布（OSS）
主模块：`P-06 桌面集成与交付`
影响模块：`P-01`、`P-03`、`P-07`、`W-03`

## 候选范围

本版收纳 `v0.0.1-rc.6` 之后已经进入 `main` 的平台工程增量，不继续扩充分析内容：

- 模型接口按供应商 Endpoint 收敛，聊天选择器读取真实模型并披露当前供应商与模型身份。
- 项目记忆、事实、摘要和会话资源按项目隔离。
- Harness Phase 7 增加项目级文件/短命令工具、统一 registry 与 policy/interceptor、受控编辑和 Provider 调用边界。
- Agent 工具调用使用结构化 ToolResult、脱敏 Trace 与兼容 SSE，并在会话中呈现真实状态、耗时、截断和副作用摘要。
- 修复打包版诊断脱敏模块仍按开发目录解析 `core/` 的启动错误；开发与 `Resources/core/` 路径均有回归覆盖。
- 科学执行继续只使用 `run_tool → tool_job → artifact truth`，没有新增第二套 executor、job、artifact 或 workflow truth。
