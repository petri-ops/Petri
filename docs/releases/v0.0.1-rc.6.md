# BioF3 Desktop v0.0.1-rc.6

发布日期：2026-07-19
状态：macOS 候选版
主模块：`P-06 桌面集成与交付`

## 主要变化

- 完成 Stage 4 首轮稳定性收口：开发态与打包态原生模块 ABI 边界明确，全量测试不再接受迁移失败。
- 修复全新用户 Runtime 首装契约：内置清单包含真实 SHA-256/大小，兼容线上旧版 manifest，并确保 R 路径修复脚本进入安装包。
- 修复 DESeq2 首次成功链：成功任务现在生成 `all_results.zip` 和自包含 `report.html`，不再依赖测试脚本补救。
- capability bundle 首次自动下载、校验、解压和挂载已由 GO/KEGG 真任务验证。
- 诊断导出改为脱敏日志和最小系统摘要，明确排除数据库、设置、对话、结果和凭据。
- macOS 构建不再隐式发布；OSS 上传只通过显式发布命令执行。

## 安装与升级

- Apple Silicon：使用 `BioF3-0.0.1-rc.6-arm64.dmg`。
- Intel：提供 `BioF3-0.0.1-rc.6.dmg` 预览包；当前没有 x64 R/Python Runtime artifact，因此不宣称支持真实分析。
- 升级前退出 BioF3，打开 DMG 后将 BioF3 拖入 Applications 覆盖旧版。用户数据保留在原目录，不随 App 删除。
- 当前版本没有 Apple Developer ID 签名或公证，macOS 可能要求在系统设置中确认打开。

## 首次使用

1. 首次分析会从官方 OSS 下载并校验 R 4.5.2 与 Python 3.11.15 Runtime。
2. 创建项目后可使用 demo 数据运行 DESeq2；成功结果应包含报告与 `all_results.zip`。
3. GO/KEGG 首次运行会自动 provision `r-enrichment` bundle。
4. 模型凭据在 macOS Keychain 保存，不会回显在设置读取接口或诊断包中。
