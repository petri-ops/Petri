## 关键修复

- 修复打包版无法加载 `shared-backend/runtime-paths` 导致应用启动崩溃的问题。
- 修复 macOS 打包态 Electron Helper/Node 执行边界与原生模块 ABI。
- 修复 migration 工作目录与 Core 文件引用安全校验。
- 保留稳定的单 bundle 生产构建，避免手工拆包引入初始化白屏。
