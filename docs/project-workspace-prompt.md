- 已把会话顶栏压薄，减少顶部占位，向 Codex 的轻量 header 靠拢。

## 当前问题

- 摘要卡是当前最高优先级：预期要尽可能复刻 Codex，现在还差得很远。
- 会话输入框还需要继续贴近 Codex 的底部 composer 形态。
- 会话区域左右留白要统一，不能一边紧贴、一边悬空。
- 右侧栏还要继续压缩卡片感，向 Codex 的浅浮层抽屉靠拢。
- 摘要卡片必须继续保持悬浮，但不能挤压主会话的垂直布局。
- 右侧面板与摘要卡的层级关系要保持轻，不要重新变成多层堆叠卡片。
- 右侧初始页要像工具启动面板，不要回到厚重信息页。
- 右侧四个常用入口要继续保持“标签 + 轻入口”的风格，不要再回到纯图标堆叠。
- 摘要卡缩放仍需继续观察交互顺滑度，若不稳优先排查 pointer 捕获和命中区域。
