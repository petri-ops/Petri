# 视觉方向 + 水印可替换方案（2026-11-25 · 设计评估产出）

> 来源：主人「我其实并不清楚要什么，只是知道 UI 要有设计感、有自己的特色风格、使用起来丝滑简单、更像国产精品；水印方向没问题但水平不咋地，需要后期可替换水印、再制作水印（比如使用生图模型自创）」。
> 性质：方向文档 + 已落地的水印素材替换实证 + 待实现的可替换能力方案。设计观感零代签（主人过目为准）。

## 一、为什么多轮优化仍不满意（病根诊断）

核 11-20～11-24 视觉改动史 + CDP 截取当前真实画面 + 实测 DOM 计算样式：

- **一直在拧螺丝，没做过构图决策**：水印手绘→AI→钢笔→极简→回退（4 轮）、字号宪章、状态色并单源、主题色稀缺化 356→316→269、默认身份面 teal→celadon-ink、断点 17→4 档……全是 token/色值/素材的逐项微调。一条提交自己承认「A0-A4 后界面几乎无变化（色差不可辨/token 零消费/亚像素/减法收敛）」。
- **水印之争是战术勤奋掩盖战略缺失**：水印改 4 轮，因为它是唯一显眼的视觉元素；但应用质感靠的是信息密度、构图节奏、控件质感、字重层级——这些没系统做。
- **字号偏小 + 低饱和 + 大面积留白**：实测正文 12.25px（对比度 5.8–18:1 达标但全页淡），WCAG 过关≠好看。整体观感「像空白草稿，不像专业生产力工具」。
- **底子是干净的**：标题层级清楚（24.5px/700/14:1）、对齐一致、零花哨、a11y 扎实。不是烂摊子，是「没长成精品」。

## 二、设计方向（一句话 + 三条原则）

**方向：国产精品 = 克制专业 + 东方身份点缀 + 丝滑简单。**

1. **克制专业**：信息有骨架——主区成组、控件有层次、次级文字有重量；不靠堆色/堆装饰，靠排版节奏和质感。参照 Linear / Raycast 的「克制但有料」。
2. **东方身份点缀**：水墨/印章做点睛，不做主角。铺低透明度水印、局部朱砂色点，但不满屏纹样。
3. **丝滑简单**：少步骤、即时反馈、动效轻；观感不代签，每次改动走主人过目。

## 三、水印：素材已替换（已完成，实证在案）

### 3.1 旧素材问题
旧图是 1536×1024 的 4 个细线圆圈（月洞门/卵石/开环/方印），线条为生图模型描出的抖动细线，无纹样肌理；opacity 0.10 铺满，观感廉价。

### 3.2 新素材（已落地）
- 用生图模型（ImageGen）按「宋代水墨远山+云雾+左上朱砂印章+大面积留白、无文字无圆圈、透明背景」生成
- ImageMagick 后处理：裁掉生图方右上角 AI/WORKBUDDY 水印字样（crop 1536×934）、浅底转 alpha（墨越深 alpha 越高，负片+level 8%,85%）、墨色统一为 #1b2b40
- alpha 统计 min=0/max=65535/mean≈7986（≈12% 覆盖，适合水印）
- 已替换 `frontend/src/assets/cultural-watermark.png`（旧图备份 `cultural-watermark.old-circle.png.bak`）
- CDP 实测：刷新后加载新图（Vite `?t=` 时间戳），欢迎页观感大幅改善——右下远山、左上印章、中间 UI 零干扰
- 候选素材留档 `frontend/src/assets/watermark-candidates/`（生成原图 + watermark-final.png）

### 3.3 待实现：水印可替换能力
现状 `watermark-ai.css` 把图片路径写死为 `url('../assets/cultural-watermark.png')`，用户无法换图/关闭/自创。方案：

- **设置页**（AppearanceSection）加「背景水印」项：控件=下拉（无 / 内置水墨 / 自定义）+ 图片上传/路径 + 透明度滑杆（0–30%）
- **持久化**：走 ThemeProvider / server user-prefs（与主题、字号同机制），不另立真相源
- **渲染**：`GlobalWatermarkAI` 读偏好动态设 backgroundImage（自定义图用 data URI 或本地文件路径），支持暗色反相沿用现有 `[data-theme='dark']` 规则
- **自定义图处理**：用户图片若带底色，提供「转透明」选项（复用本次 ImageMagick 的 alpha 提取逻辑，前端 canvas 实现）
- **生图自创**：一期先支持「导入自定义图片」；「应用内生图」作为后续能力（涉及 Provider 预算/额度，另裁决），不强绑定
- 观感零代签；HK-01 红绿先行；不碰主人 dev 实例进程（HMR 落窗口）
