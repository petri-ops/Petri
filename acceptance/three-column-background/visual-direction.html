Petri · 三栏背景分区三方案（提案视觉稿）

三栏现状均为同一种背景色；以下方案用既有 token 的 color-mix 派生 2-4% 极淡 tint。静态稿、非实现、观感零代签。

切换亮/暗看双模式表现；每屏左=现状、右=提案。

方案 A — 极淡单色差分区（三栏各一层 tint）

左略深 / 中主底 / 右略冷，分界处渐变淡出避免硬边。

token：color-mix(bg-surface 96%, text/accent 4%)，中栏不动；暗色随双定义自动适配。分隔线（border-strong）保留可见。

方案 B — 仅左右两侧 tint（推荐）

中栏（对话主体）纯主底完全不动；左栏微深、右栏微浅，建立「外围辅助 / 中心主内容」。

token：左 color-mix(bg-surface 96%, text 4%)、右 color-mix(bg-surface 80%, bg-subtle 20%)；暗色下 subtle 更亮→右栏微亮，方向自然反转。中栏消息气泡/卡片可读性零影响。

方案 C — 顶部纵向渐变 tint

每栏从顶部极淡渐变到主底，无横向硬边；更柔和但分区信号最弱。

token：linear-gradient(180deg, color-mix(bg-surface 94%, accent/text 6%), bg-surface 110px)；长列表滚动时渐变锚容器顶部、分区感随内容滚动减弱。
