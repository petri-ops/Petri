# 合成演练稿：基于合成转录组数据的分析方法评估（虚构）

> 全文为合成夹具。所有数字、样本量、p 值均为演练用虚构值，不对应任何真实实验。

## 摘要

随着高通量测序技术的快速发展，基于转录组的差异分析方法被广泛应用于生物学研究中。本研究针对合成数据集，对三种差异分析流程进行了系统的比较与评估，共纳入 24 个合成样本（对照组 12 例，处理组 12 例）。结果显示，流程 A 在合成条件下检出的差异基因数为 1,248 个，流程 B 为 1,173 个，流程 C 为 1,206 个；其中流程 A 的假阳性率估计为 0.031（合成真值已知）。综上所述，合理的流程选择对结果具有的重要意义，为后续合成数据基准研究奠定了基础。

## 方法

本研究使用合成转录组计数矩阵（24 样本 × 8,000 基因）。计数经 TMM 归一化后，分别采用流程 A（阈值 p < 0.05 且 |log2FC| ≥ 1）、流程 B（p < 0.01）、流程 C（Benjamini–Hochberg 校正后 q < 0.05）进行分析。所有分析均在 R 4.5.2 环境下完成，随机种子固定为 20261123。

## 结果

在合成条件下，流程 A 检出 1,248 个差异基因，其中上调 612 个、下调 636 个；流程 B 检出 1,173 个；流程 C 检出 1,206 个。流程 A 的假阳性率估计为 0.031，灵敏度为 0.872（基于合成真值）。三组间检出数差异经合成标注比较，p = 0.042。上述差异提示不同流程在合成条件下存在性能差别。

## 讨论

本研究表明流程 A 在本合成设置下具有较高灵敏度，但这一结果仅在合成数据上得到初步显示，尚未在真实生物样本中验证。研究的局限性包括：合成模型未覆盖批次效应；样本量（n = 24）有限；未测试非编码 RNA 场景。作者未声明任何真实数据集或伦理批准信息（本稿为合成演练）。
