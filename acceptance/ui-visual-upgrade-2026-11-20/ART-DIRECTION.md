# 格物 UI 艺术指导方案（Art Direction · advisory）

> **补的是什么**：上一份 `VISUAL-UPGRADE-PLAN.md` 解决"判据与门禁"，但没回答你问的**审美问题**——用什么视觉世界、什么和色调、什么造型语言、图标什么角度。本文件回答这四个，且**落在一个已经存在、已成稿、但从未接入 UI 的品牌资产上**。
> **边界**：不占串行槽位、不改产品代码、不翻观感状态。身份级改动（换色阶/换 surface 基调）U 类，需你裁决后才立项。G0 开发期常态 · 不外推 packaged/Provider/GA。

---

## 0. 核心发现：UI 与品牌是两套视觉语言

工作区 `petri-logo-concepts_assets/`（60+ 件，2026-11-05～16 生成，未跟踪用户资产）里有一套完整、定稿级的品牌系统，UI 完全没有采用它：

| 品牌资产已定义的 | 当前 UI 实际用的 | 落差 |
|---|---|---|
| 宣纸 #F2EFE6 / 墨 #1C1B19 / 朱砂 #B5482F / 灰 #8A8578（`01-system-board.png`） | zinc/纯白亮色 + teal #0d9488 强调 + 海军蓝暗色四阶 | **身份断链**：品牌是东方纸墨朱砂，UI 是通用 SaaS navy/teal |
| 另外三套调和色试样（`00-palette.png`）：青瓷·墨 / 群青·铜 / 靛·雾 | 只有 teal 一套 accent，且 5 个 data-accent 主题各不相干 | **调色体系缺位**：没有"骨架色 + 点睛色"的和声关系 |
| 开环圆环 + 错落四格（一格点睛，面积 <5%）的造型语法（`FINAL-grid-contact.png`） | 界面无此形态语言，图标是通用 Phosphor/lucide 线性 | **造型与图标没有品牌指纹** |
| 竖排标题（字距 1.15×）、英文横排小字作注脚、朱印落在标题下方、发丝线分隔、内容占比 ≤40%、"不圆满、不填满、不解释"（`01-system-board.png`） | 界面是 14px 横排 + 卡片填满 + 分割线密布 | **东方留白语境完全缺失** |

**结论**：你感到"普通"的根因不是打磨不够，是**产品没有穿着自己的视觉身份**。最大的质感跃迁 = 把这套已定稿的东方视觉语境翻译成桌面 agent UI 的 token 与组件语言——这是任何通用模板给不了的形态。

## 1. 艺术方向定位（一句话）

> **"一台跑在宣纸上的精确仪器"**：骨架用墨与留白建立秩序，点睛用一味朱砂/群青标记"被格出来的那一格"；形态取开环与错落格，图标取 3/4 俯视微倾的几何线性，动效只有落印式的一次到位。

- **不抄**：不复制任何品牌 logo 到 UI 当装饰、不做水墨渲染/毛笔笔触/中式纹样贴皮、不把营销页 CTA 搬进 agent 工作台。
- **借的是**：色彩和声关系、造型语法、留白纪律、点睛面积纪律——即 `reference-board-review.json` 允许的"只取设计原子"。
- **与魂一致**：东方视觉语境是**形**（辨识度），本地主权/可审计/证据自证仍是**魂**（不可替代性）；open-ring"缺口"恰是"自 hosting、留有余地"的形态隐喻。

## 2. 调和配色体系（第一问：配色用调和色）

### 2.1 配色方法：骨架 + 点睛二段和声（不是随机选色）

四套已定稿试样都是同一个和声结构：**一个中性骨架色（纸/霜）+ 一个深色结构色（墨/墨蓝）+ 一个点睛色**。点睛色只占 <5% 面积、只落在"那一格"。这是东方"朱印"逻辑，比通用 SaaS 的"主色+强调色+状态色全家桶"更有纪律、更高级。

| 方案 | 纸/霜 | 墨/结构 | 点睛 | 气质与适用 |
|---|---|---|---|---|
| **A 宣纸·朱砂**（品牌主张，`01-system-board.png`） | 宣纸 #F2EFE6 | 墨 #1C1B19 | 朱砂 #B5482F | 最纯正、最有身份；建议作为**默认品牌面**（欢迎页/设置/关于/空态/品牌点缀） |
| **B 青瓷·墨**（现行 accent 的东方化） | #F4F1E8 | #173A38 | #2FF7D72（青瓷） | 延续 teal 认知但降饱和入东方语境；建议作为**工作态主 accent 迁移目标** |
| **C 群青·铜**（`final-brand.png` 采用） | #F2EFE6 | #1E2E52 | 黄铜 #A87C42 | 学术档案感、最贵气；适合结果/证据/归档面 |
| **D 靛·雾**（冷科技、最国际化） | 雾蓝 #EAEFF2 | #1B2B40 | #6E9CA0 | 最安全、最像工具；适合数据密集/表格/图表面 |

**推荐落地策略（单一建议，不甩菜单）**：以 **B 青瓷·墨** 为全局 accent 迁移目标（尊重用户既有 teal 认知与"主题色一致"偏好），在**品牌表达面**用 **A 宣纸·朱砂** 做局部点睛，在**证据/归档面**用 **C 群青·铜** 的铜色作 success/evidence 语义——**一套和声家族，按语义分工，不是三套并列主题**。

### 2.2 和声规则的机械表达（不违反 token 契约）

- 所有色值进入 `--petri-*` 单一家族：新增 `--petri-ink-{paper,ink,vermilion,celadon,brass,frost…}`，亮暗双套定义，禁止裸 hex 进组件。
- **点睛面积纪律**：CSS 层面把点睛 token 只映射到 `accent / selected / focus / brand-mark` 四类语义；装饰面默认墨/纸中性（与 charter "accent 五语义 + 10:1 + ≤130 + 每视图 ≤8" 完全兼容，且 A/B/C/D 都收敛 accent 引用）。
- **对比度硬底线不放松**：朱砂 #B5482F 在宣纸上 ~5.4:1、群青 #1E2E52 在宣纸上 >10:1、黄铜 #A87C42 在深底需提亮到 #C9A063 才达正文 4.5:1——这些进 token 前逐对实测，`gate:ui-a11y` 零违规。
- **云锦不抢戏**：状态色（success/warning/error）保持既有 `--petri-status-*`，只让"点睛色"系列承担品牌/选中/焦点，避免语义打架。

## 3. 造型语言（第二问：形态）

从品牌 mark 抽象出三条可复用的造型规则（来源是 `FINAL-grid-contact.png` 的"错落格"与 `01-system-board.png` 的"不圆满"）：

1. **开环（open ring）**：容器/进度/状态指示不用全闭合圆环，留一个缺角——"不圆满、留余地"。可用于：加载指示（开环旋转）、完成度、会话状态点外圈、空态插画。禁止：把圆环强行封合成饼图/进度环的俗套。
2. **错落四格（offset quadrants）**：2×2 网格中恰有一格被"格出"（点睛色或反白），其余为结构色。可用于：结果面板的"当前焦点"标记、多 tab 的 active 指示、仪表卡的一组 KPI（一格点睛、三格墨）、空态图示。纪律：**点睛格 ≤1/视图**，其余同色。
3. **发丝线与留白**：分隔用 1px 发丝线（不是卡片描边），内容占比 ≤40%，其余留白。与 charter "分隔优先序 留白 > 底色差 > divider" 和 BLOCK-423 "少线条" 完全一致——东方语境给了这条纪律一个**文化理由**，不只是机械约束。

**卡片与容器**：卡片不用"白底圆角 + 细边 + 阴影"三件套；改为**纸面区块 + 发丝线分组 + 错落格点睛**，圆角用既有 4/6/8 档但偏小（东方器物偏方正），阴影只在浮层用且为柔和 offset（不玻璃、不发光、不渐变）。

## 4. 图标角度与笔画（第三问：图标角度）

品牌 mark 是**平面正视几何**（同心开环 + 方形错落格），因此图标系统应取同一视角家族，而不是混搭 3D/等距：

- **视角**：正视平面（front-on），零透视、零等距、零 3D 倾斜——与"格物"的器物平面性一致。图标在 24px 网格内光学居中，笔画端点齐平。
- **笔画**：outline 线性、1.5px 基准（16px 图标 1.25px / 24px 图标 1.5px / 32px 图标 2px），圆角端帽，几何弧线；负空间用开环缺口而非闭合描边。
- **点睛纪律**：图标默认墨色（`--petri-text-secondary`）；**只有"当前激活态/唯一主行动"图标可用点睛色**，且遵循品牌"一格点睛"——一屏最多一个彩色图标。状态图标走 status token，不混用点睛色。
- **形态语汇**，取自 mark 的原子：环（流程/循环/运行中）、格（列表/视图/网格/结果）、缺口（停止/中断/未完成）、错位方块（移动/重排/分支）。优先用这些原子构造自绘 SVG，而不是堆通用图标库。
- **来源与许可**：`ui-ux-pro-max` icons.csv（Phosphor，105 枚目录）给出语义角色/可访问性用法；**只借语义分类与 a11y 规则**（aria-hidden / 交互控件须有可访问名），不引入 `@phosphor-icons/react` 依赖；采用项目内自绘 SVG，单一 `Icon` 组件真源（复用 controls 五件套纪律）。数据库检索发现：专门"outline/geometric"图标风格查询 0 结果，已按 skill 规则重试 `navigation list arrow` 得到 8 条（均为 Phosphor Outline），作为语义与笔宽参考而非风格裁决。

## 5. 字体与排版语境（第四问：字）

`01-system-board.png` 定义了东方排版：中文竖排标题（字距 1.15×）、英文横排小字作注脚、朱印落款。桌面 agent UI 不能全竖排（可读性/控件密度），但可翻译：

- **标题层级**：重要页面标题用**更宽字距 + 更重字重**（模拟竖排标题的重量），英文/技术标签保持横排小字作注脚——即"中主英辅"的双语层级。
- **落印位**：品牌点睛色只在页面标题区下方落一小块印（2-4px 细长条或 6px 方点），与 UI-705 已 verified 的 UpdatePill 形态同源，不新增花哨 badge。
- **字体选择**：不引入新字体（零新依赖 + 系统字体优先）；中文用系统栈，英文/代码用 `--petri-font-mono`。数据库 typography 给出 Science/Tech（Exo+Roboto Mono）与 Developer Mono（JetBrains Mono+IBM Plex Sans）两组"精确仪器"参考，**仅作气质对照，不落地为依赖**。

## 6. 与既有门禁的关系（艺术方向不破坏纪律）

| 既有 canonical | 本方案如何遵守 |
|---|---|
| `design-charter.md` 字号 6 档 / 10:1 / accent≤130 / 每视图≤8 | 点睛色就是 accent 的东方命名，面积纪律比 charter 更严（<5%），不冲突 |
| `petri-css-theme` 禁裸色 / 禁 slate / 明暗双套 | 所有新色入 `--petri-*` 亮暗双套；宣纸系暖中性替代 zinc 属**U 类身份级裁决** |
| 20+ 机械门 + output:judge + 观感预审闭环 | 沿用；本方案只增加"艺术方向一致性"人眼判据（点睛是否只有一格、图标是否同视角、留白是否 ≥40%） |
| zero new dependencies | 图标自绘 SVG、字体系统栈、色值 CSS 变量——零新增 |
