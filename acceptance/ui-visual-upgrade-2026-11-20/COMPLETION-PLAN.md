# 视觉升级收尾计划（advisory · 每期独立发令）

## 0. 诚实诊断：为什么 A0–A4 之后界面几乎没变

| 层 | 事实 | 后果 |
|---|---|---|
| A0 色彩裁决 | 选「B 青瓷·墨 延续 teal」：celadon `#0f766e`/`#2fd7d2` vs 现有 `#0d9488`/`#2dd4bf` | 色差肉眼不可辨，等于选了"不变" |
| A1 token | 四身份 token 仅定义于 `custom.css`，消费点只有契约测试自身 | 零组件消费 = 零视觉变化 |
| A2 原子 | 三原子只落 MCP 空态 + 扩展 active tab 两处 | 需要主动去那个页面才看得见 |
| A3 排版 | 字距 0.03–0.04em = 14px 字上 0.4px；落印位 3px | 亚像素级，无对照不可感 |
| V1/V1-U | accent 356→269 是**减法**（去掉装饰色） | 更空，不等于更美 |

**结论**：已交付的是判断基础设施（契约/棘轮/测试/文档/skill），不是像素。要真正可见，必须新增"身份面上线"期，把和声接到真实组件，并选一个**真的不一样**的品牌面。

## 1. 收尾分期（建议序 · 每期独立发令 · 单工作包串行）

| 期 | 范围 | 机械验收 | 观感 |
|---|---|---|---|
| **U 类裁决包（前置）** | ①是否启用「宣纸·朱砂」或「群青·铜」作**可见**品牌面（不选则维持现状，后续均不可见）②目标分 4.4 是否采纳 ③断点 17→≤4 档值 ④状态色三套是否合并 | 裁决入 AUDIT-LOG + 材料 append-only；未裁不动代码 | — |
| **V5 身份面上线（新增·核心）** | 把裁定的品牌面接到 3–5 个真实高频面：欢迎页 hero / 设置分区标题 / 空态 / 证据卡点睛；`--petri-accent` 与身份 token 建立单一派生关系；点睛面积 <5% 实证 | 新 token 消费点 ≥10 组件；accent 棘轮不回潮；对比度 32 对 0 违规；点睛面积脚本实测 <5% | 偏好预审 ≤3 轮（标准=文字少/布局和谐/主题色一致） |
| **V0 基线冻结（补做）** | 评分卡/颜色预算/台账 triage/design-context sha 注册为对账基线 | 19/19 + docs + hygiene 绿；字段现读逐项相等 | 无 |
| **V2 层级与布局单源** | 裸 z-index 111→`--petri-z-*`；CenterPanel 双 layout 合并；宽度预算显式；扫描面 rows-not-cards | 四块几何全绿、≤900px 不越界、拆前拆后同套测试绿 | 不代签 |
| **V3 浏览器表面与细节** | caret/selection/scrollbar/focus/tabular token 化；阴影归位；文案句式；`;;` 归零 | 裸色 0、focus-visible 全覆盖、a11y 绿 | 截图预审 ≤3 轮 |
| **V4 复测与台账回写** | Before/After 同套评分卡；新判据违规必红负测；UI 台账批量回写 | ui:audit 绿、负测 100%、closeout 绿 | 按 11-20 裁决 |

## 2. 关键判断

- **V5 是整个收尾的杠杆**：跳过它，V0/V2/V3/V4 做得再规范，界面仍然"没变化"——只是更规范的旧界面。
- **V5 的前提是 U 类裁决**：不换可见品牌面，就只能得到"青瓷≈teal"的零效果。必须由用户明确选一个**与现状有辨识度差**的方向。
- **V2 的断点档值是 U 类**，进 V2 前须裁；状态色家族合并属 breaking，可 deferred 单独票。
- 每期均为新工作包，须用户逐期发令；本文件不构成开工。
