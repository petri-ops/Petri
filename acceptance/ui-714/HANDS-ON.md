## 判断标准（逐条过，全部满足才签 verified）

### ① chart（真实会话，亮+暗各一张）

| # | 判据 | 不通过的样子 |
|---|---|---|
| C1 | 柱状/折线图形在场（svg），**不是一段 JSON 文本** | 卡里是 `{"kind":"bar"...}` 原文 |
| C2 | 数值标注（120/145/132）与图例（tok/s）可读 | 数值/图例缺失或叠字 |
| C3 | **暗色下柱体清晰可辨**（有描边或提亮填充，不是黑底黑柱） | 暗色下柱体几乎看不见 |
| C4 | 卡内无布局溢出/裁切，标题「速度对比」在场 | 溢出容器或标题丢失 |

### ② 暗色 hover（两张对比图）

| # | 判据 | 不通过的样子 |
|---|---|---|
| H1 | 模型按钮 hover 提亮与相邻图标钮 hover **同一档**（肉眼无「更浅/更深一档」感） | 并排一深一浅 |
| H2 | hover 提亮可见但不过曝（仍是背景微亮，非高亮块） | 出现突兀亮块 |

### ③ 左栏选中态（顺带看，不单独签字——已在 UI-714 加映二实机断言）

「扩展」项有选中描边且与其余项可区分即可。
